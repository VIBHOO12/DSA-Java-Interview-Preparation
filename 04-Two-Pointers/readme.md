## Key Patterns

### Opposite Direction
```text
left →        ← right
```

Used for:
- Reverse
- Palindrome
- Pair Sum

### Same Direction
```text
slow → fast →
```

Used for:
- Remove duplicates
- Move zeroes
- In-place array modifications

## Complexity

| Problem | Time | Space |
|---|---|---|
| Reverse Array | O(n) | O(1) |

| Move Zeroes | O(n) | O(1) |
