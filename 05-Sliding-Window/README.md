# Day 05 — Sliding Window

## Topics

* Sliding Window
* Fixed Size Window
* Variable Size Window
* Subarray Sum
* Window Expansion & Shrinking

## Problems Solved

1. Maximum sum subarray of size K
2. Minimum sum subarray of size K
3. Maximum average subarray


## Key Patterns

### Fixed Window

```text
Window Size = K
```

Used for:

* Maximum sum of size K
* Minimum sum of size K
* Maximum average of size K

### Variable Window

```text
Expand → Check Condition → Shrink
```

Used for:

* Minimum/maximum length subarrays
* Substring problems
* Longest/shortest window problems

## Complexity

| Problem                 | Time | Space |
| ----------------------- | ---- | ----- |
| Fixed Sliding Window    | O(n) | O(1)  |
| Variable Sliding Window | O(n) | O(1)  |
