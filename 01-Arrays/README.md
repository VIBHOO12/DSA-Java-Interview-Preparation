## 🧠 Key Pattern

### Two Pointer Technique

Two pointers are used to process an array from both ends.

```text
left →              ← right
[ 1   2   3   4   5 ]
```

This technique can be used for problems such as:

* Reversing an array
* Pair sum problems
* Palindrome problems
* Partitioning problems

## ⏱️ Complexity

| Problem   | Time | Space |
| --------- | ---: | ----: |
| Traversal | O(n) |  O(1) |
| Sum       | O(n) |  O(1) |
| Maximum   | O(n) |  O(1) |
| Minimum   | O(n) |  O(1) |
| Reverse   | O(n) |  O(1) |

## 🎯 Interview Takeaways

* Array indexing provides O(1) access.
* Linear traversal generally takes O(n) time.
* Avoid sorting when a linear-time solution is possible.
* Two Pointer technique can reduce extra space requirements.
