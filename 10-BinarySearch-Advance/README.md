# Day 10 — Binary Search Advanced

## Topics
- First Occurrence
- Last Occurrence
- Search Insert Position
- Square Root using Binary Search
- Search in Rotated Sorted Array

## Key Patterns

First Occurrence:
target found → move right boundary left

Last Occurrence:
target found → move left boundary right

Rotated Array:
identify the sorted half → search the valid half

## Complexity

Most problems:
Time: O(log n)
Space: O(1)
