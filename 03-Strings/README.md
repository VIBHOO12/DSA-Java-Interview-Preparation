## Problems Solved

1. Count vowels
2. Count digits

## Key Patterns

**String Traversal**

```text
charAt(i)
```

**Palindrome**

```text
left → ← right
```

**Character Frequency**

```text
freq[ch - 'a']++
```

## Complexity

| Problem     | Time | Space |
| ----------- | ---- | ----- |
| Vowel Count | O(n) | O(1)  |
| Digit Count | O(n) | O(1)  |
| Reverse     | O(n) | O(n)  |
| Palindrome  | O(n) | O(1)  |
| Frequency   | O(n) | O(1)  |
